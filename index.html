Virtual Event Management

A web app for college event planning. The admin creates and announces events, students register online and receive a QR code entry pass by email, and attendance is marked by scanning that code at the event.

Features

  • Admin-only managementOnly the admin can log in to add, edit and update events.
  • Event announcementsThe admin creates an event with a form and publishes it as an announcement for students.
  • Student registrationStudents register for an event online and get a confirmation by email.
  • QR code entry passAfter registering, each student receives a QR code by email, which works as their entry pass.
  • Attendance scanningOn the event day, the admin logs in and scans each student's QR code to mark them present or absent.
  • Year-wise organizationEvents are grouped by year, like a folder for each year, so past events are easy to find.
  • DashboardDashboard counts for events, registrations and attendance.
  • DownloadsDownload registration and attendance details.
